# راهنمای فارسی GlobalCare

GlobalCare یک داشبورد جست‌وجوی آگهی‌های شغلی پرستاری است. این مخزن شامل نمونهٔ رابط کاربری و الگوی اتصال به Cloudflare است؛ تا زمانی که Cloudflare پیکربندی و انتشار موفق تأیید نشود، سایت آنلاین محسوب نمی‌شود.

## وضعیت و محدودیت‌ها
- داشبورد درخواست استخدام ارسال نمی‌کند.
- فیدهای فعلی عمومی و محدودند و پوشش جامع آمریکا، بریتانیا، استرالیا و هلند را تضمین نمی‌کنند.
- آگهی‌ها را در وب‌سایت رسمی کارفرما بررسی کنید؛ اطلاعات و شرایط ممکن است تغییر کند.
- هرگز توکن یا رمز را در مخزن عمومی commit نکنید.

## ساختار
- `index.html`: رابط داشبورد
- `functions/api/jobs.js`: نمونهٔ API خواندنی برای Cloudflare Pages Functions
- `collector/worker.js`: جمع‌آورندهٔ زمان‌بندی‌شده
- `collector/wrangler.toml`: الگوی پیکربندی Worker و D1
- `sql/schema.sql`: ساختار پایگاه داده
- `.github/workflows/deploy-pages.yml`: نمونهٔ گردش کار انتشار

## راه‌اندازی
1. مخزن را به Cloudflare Pages وصل کنید و دایرکتوری خروجی را مطابق ساختار پروژه تنظیم کنید.
2. یک D1 database با نام `globalcare-db` بسازید و `sql/schema.sql` را در Console اجرا کنید.
3. شناسهٔ واقعی دیتابیس را در `collector/wrangler.toml` قرار دهید؛ مقدار placeholder را باقی نگذارید.
4. از پوشهٔ `collector` با Wrangler وارد حساب شوید و Worker را deploy کنید.
5. مقدار `ADMIN_TOKEN` را فقط به‌صورت secret در Cloudflare تنظیم کنید.
6. برای Pages Functions، binding دیتابیس با نام `DB` را تنظیم کنید.
7. اگر GitHub Actions را انتخاب می‌کنید، secrets لازم `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID` را در تنظیمات مخزن وارد کنید.
8. اجرای workflow را بررسی کنید و فقط پس از Deploy موفق، URL تولیدشدهٔ Pages را به‌عنوان سایت زنده اعلام کنید.

## زمان‌بندی
نمونهٔ Worker برای اجرای روزانه در ساعت 06:00 UTC تنظیم شده است.

این بسته نمونهٔ اولیه است و قبل از استفادهٔ عملی باید تنظیمات محیطی، پوشش فیدها، مدیریت خطا و خروجی‌های API را آزمایش کنید. هیچ درخواست شغلی خودکاری ارسال نمی‌شود.
